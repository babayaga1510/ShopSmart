
# ShopSmart

A responsive static storefront built with HTML, CSS and JavaScript.

## Features

- Responsive design
- Product cards
- Interactive demo cart
- Nginx-compatible static files
- No framework or build process required

## Run locally

From the project folder:

    python3 -m http.server 8080

Open http://localhost:8080 in your browser.

## Deploy

See the EC2 and Nginx deployment steps below.

Note: This is a demo website. The cart is not persistent and no real checkout or payment processing is implemented.
